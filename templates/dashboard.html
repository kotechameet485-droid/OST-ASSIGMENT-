How is this calculated?
  • Activity (25% Weight): Evaluates commit recency (days since latest push) and commit velocity (commits/day). Repositories pushed within 3-7 days receive top marks.
  • Issue Management (20% Weight): Calculated from sample resolution rate, median resolution days (robust against long-open outliers), and open backlog ratio.
  • PR Activity (20% Weight): Calculated from pull request merge rate and turnaround velocity for merged contributions.
  • Contributor Diversity (15% Weight): Evaluates maintainer volume and maintainer concentration via the Herfindahl-Hirschman Index (HHI = Σ share²).
  • Maintenance & Hygiene (20% Weight): Validates documented open-source license presence, project purpose description, topics, and non-archived status.

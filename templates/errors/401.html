GitHub Token Authentication Failed

The GITHUB_TOKEN provided in your local .env file was rejected by GitHub (HTTP 401). The token may have expired, been revoked, or contains a typographical error.

How to resolve:
  1. Generate a fresh personal access token at GitHub → Settings → Developer settings → Personal access tokens.
  2. Ensure public_repo read scope is selected.
  3. Update the GITHUB_TOKEN variable in your .env file.
  4. Restart the Django application server.

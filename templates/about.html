OpenSourceLens Platform Architecture

A production-style foundation for analyzing open-source software health, development metrics, and community sustainability.

System Data Pipeline 

USER
  ↓
DJANGO WEB APPLICATION (Controllers & Views)
  ↓
REPOSITORY INPUT (Validation & Sanitization)
  ↓
GITHUB API SERVICE (Authenticated REST Client & Rate Limiting)
  ↓
GITHUB PUBLIC DATA (JSON Payloads & Headers)
  ↓
POSTGRESQL (Relational Models: Repositories, Contributors, Languages, Issues, PRs)
  ↓
PANDAS / ANALYTICS (DataFrames, Vectorized Percentage Distributions)
  ↓
HEALTH METRICS (5 Weighted Pillars: Activity, Issues, PRs, Diversity, Maintenance)
  ↓
INTERACTIVE DASHBOARD (Bootstrap 5 + Custom Design System)

Health Score Formula

Rather than arbitrary vanity metrics, OpenSourceLens establishes transparent weights based on maintainability:

  • Activity (Push recency, release cadence) 25%
  • Issue Management (Ratio to community scale) 20%
  • PR Activity (Review velocity, status) 20%
  • Contributor Diversity (Community distribution) 15%
  • Maintenance & Hygiene (License, specs) 20%

Technology Stack

  • Backend: Python, Django 6, Django ORM, Django Templates
  • Database: PostgreSQL (relational foreign key constraints)
  • Data Processing: Pandas DataFrames
  • External API: GitHub REST API v3
  • Frontend: HTML5, CSS3, JavaScript, Bootstrap 5, Bootstrap Icons
  • Design System: Developer tooling aesthetic (clean slate/charcoal)
  • Environment: Python-dotenv configuration (.env)

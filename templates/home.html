Engineered for Open-Source Transparency

OpenSourceLens processes public software engineering telemetry through a deterministic data pipeline.

1. Real-Time Ingestion

Pulls authentic metadata, stars, forks, watcher counts, open issues, and languages directly from GitHub REST API with real pagination.

2. PostgreSQL Persistence

Structured relational tables for repositories, contributors, commit activity, issues, and PR velocity with database transaction protection.

3. Pandas Analytics

Vectorized DataFrame aggregations, language distributions, issue resolution median days, PR merge turnaround, and maintainer HHI concentration.

4. 5-Pillar Health Scoring

Deterministic multi-signal health index across Activity (25%), Issues (20%), PRs (20%), Diversity (15%), and Maintenance (20%).
